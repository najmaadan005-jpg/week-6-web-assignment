# 💰 SpendWise

SpendWise is a simple budgeting and expense-tracking web application built using HTML, CSS, and JavaScript. The application helps users manage expenses, monitor spending, and determine whether they are within their budget.

## 🚀 Features

- Add expense categories and amounts
- Store multiple expense records using arrays
- Display expenses dynamically on the webpage
- Calculate total spending automatically
- Check if spending exceeds the budget
- Update content using DOM manipulation
- Respond to user actions with event listeners
- Interactive and user-friendly dashboard

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
